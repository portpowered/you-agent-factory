## Rules for interpreting this inventory

- All service owners receive real, completed, required collaborators directly. Their constructors retain those arguments; they do not manufacture a replacement when an argument is nil.
- Boundary configuration can select implementations before injection. Normalize replacements/default policy once in canonical composition, then pass concrete effects. Remove service-level fallback and optional dependency-construction paths.
- Validate malformed external configuration and caller-facing composition once where necessary. Typed-nil validation is an error path, never permission to select a noop or real replacement.
- Keep nullable request fields, absent session/runtime handling, contexts, cancellation, and resource lifecycle checks where their behavior requires them. They are not dependency fallback targets.
- Multiple stateless `Real{}` values read the same host clock. The meaningful problem is fake/deterministic override bypass and inconsistent timer capability, not allocation overhead.
- Share one explicitly selected process wall source and compatible scheduling capabilities by default. Keep replay/logical time separate from OS cleanup and network deadline time. Do not silently switch clocks when a capability assertion fails.
- Preserve domain-owned narrow clock interfaces and logger adapters backed by shared instances. A metadata-derived logger or scoped file sink is not automatically a redundant backend.
- Preserve explicit edge-specific overrides during caller migration, with precedence and observable propagation tests. Do not remove `HostedClock`, `ModelHostClock`, `PlatformProcessClock`, `AgyPTYClock`, `FactoryDefinitionClock`, `FactoryWebhookClock`, or `WorkContentStagingClock` merely because their defaults can share a source.
- Preserve registries, attempts, marks, buffers, scope configurations, file sinks, recording handles, and close/cancel handles under their owners. Replace cached service graphs with scope-keyed state/resources; do not flatten canonical state into a global mutable bag.
- Delete compatibility paths only after production and test caller migration. Explicit inert test collaborators belong in test fixtures; tests must use the same typed production constructor shapes.
- `pkg/wire/wire.go` and generated `wire_gen.go` have one integration owner. Leaf lanes can prepare provider signatures independently; integration consumes those settled signatures and regenerates once per coherent increment.
- Public HTTP/CLI behavior, event identity/order, replay results, retry policy, and persistence guarantees are preservation requirements. Changing a fallback that silently discards durable persistence needs an explicit failure criterion and characterization evidence.
