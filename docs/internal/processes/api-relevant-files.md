# API Relevant Files

Use this map when changing the public REST contract.

- `api/openapi-main.yaml` is the authored OpenAPI entrypoint. Register new component fragments under `components.schemas` here.
- `api/components/schemas/api/` contains API request/response fragments.
- `api/components/schemas/data-models/` contains customer-facing factory and work data model fragments.
- `api/openapi.yaml`, `pkg/api/generated/server.gen.go`, `pkg/generatedclient/client.gen.go`, and `ui/src/api/generated/openapi.ts` are generated by `make generate-api`.
- `pkg/api/contracttests/` contains OpenAPI authoring, bundled-contract, and generated-type smoke tests for public API changes.
- Adding a new OpenAPI operation updates `factoryapi.ServerInterface`; add or update the matching `pkg/api` handler before running package tests.
- Managed-runtime discovery and inspect projection live in `pkg/localmodels/catalog.go` and `pkg/localmodels/managed_runtime.go`; wire runtime cache and source resolver inputs through `localmodels.CatalogOptions` from `pkg/service/model_catalog.go`.
