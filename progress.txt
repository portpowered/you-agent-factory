## Codebase Patterns
- Public CLI commands are authored in `contracts/cli/commands.json`; update the matching family ID list, constructor bindings, handler registry, and generated CLI artifacts together.
- Run `go run ./cmd/climanifestgen -root .` for CLI family artifacts and `go run ./cmd/contractsgenerate -root .` for published contract staging; `climanifest-check`, `contracts-check`, and CLI contract smoke catch drift.
- CLI identity and input baselines are rewritten through the `UPDATE_CLI_BASELINES=1` test helpers; run writers one package at a time because command and input baselines are shared files.
- Generated Work leaves without authored positional arguments preserve the existing inventory behavior; apply `cobra.NoArgs` only when a new command explicitly requires rejecting positional input.
- Long-lived CLI event streams use a dedicated no-timeout `clihttp.Protocol` and consume the canonical SSE route through generated Factory Event payload types.
- Reconnectable CLI streams should pass the reducer's last accepted canonical event ID and sequence as server cursors; keep deduplication and ordering in the reducer and cap retries for the whole invocation.
- Use `context.AfterFunc` to close an active stream body on cancellation so blocked reads and reconnect backoff can unwind without polling or a durable cursor journal.
- Public event-driven Work observers should drive transitions through the public `you work move` edge in end-to-end fixtures; worker dispatch completion events are distinct from canonical `WORK_STATE_CHANGE` observation.
