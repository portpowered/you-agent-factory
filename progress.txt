## Codebase Patterns
- Public service-root contracts own peer-facing operations; keep provider readers, recording stores, and filesystem effects behind the owning root service.
- Cross-service dependencies are composed in `pkg/wire`; after changing a provider signature, run `make generate-wire` and keep generated wiring synchronized.
- Canonical Events subscriptions start from a topic-bound zero cursor to replay retained records, then use context cancellation to unregister the live subscriber.
- Additive methods on a root interface require every test double and delegating spy to forward or stub the new methods before the repository can compile.
- Deterministic read projections sort stable identities, and active elapsed-time projections use an injected clock while terminal values use the captured terminal timestamp.
- Public CLI command families require synchronized authored manifests, generated family metadata, staged package artifacts, and user-visible help/command/input baselines.
- Coverage baselines are lane-specific; every measurable package needs an explicit unit or functional entry, including a measured `0.00` floor when that lane has no covered statements.
- Functional coverage floors should be repaired with observable customer behavior through `Process.Execute`, not source-inventory or command-topology meta tests.
- List and show observation JSON should share one normalized document mapper so optional values keep identical `null` semantics across commands.
- Public API changes require synchronizing the bundled contract, generated Go/dashboard/package clients, and error-code schema before API smoke checks.
- Long-lived CLI event streams use an HTTP transport without a request timeout and must carry explicit terminal/source-failure outcomes; EOF without a terminal frame is a typed stream failure.
- Finished transcript reads must check the Worker Session lifecycle before invoking Provider Sessions so active sessions have a deterministic typed outcome and never trigger raw-source fallback.
- Hosted session and decorator wrappers must forward optional runtime capability interfaces before HTTP binding, or service-mode routes can disappear while the broad root contract still works.
- Runtime list decorators should source identity, correlation, lifecycle, and timing from canonical recording projections, then merge only normalized detail owned by a peer root.
- Historical exact-session lookup must resolve identity, correlation, lifecycle, and timing from canonical Factory recording facts, then enrich normalized detail/transcripts through Provider Sessions; process-local registries are not authoritative after replay.
- If a capability already belongs to a service root, preserve compatibility with a public alias or local consumer interface instead of adding a second named root interface.
- Package file-count baselines are exact deletion-only gates; consolidate feature helpers into existing owner files when a package is already at its limit.
- Canonical ledger streams must carry domain scope and capacity into the source subscription; consumer-side filtering alone still lets unrelated events exhaust upstream buffers.
- Preserve legacy unscoped reconnect history when no explicit stream limit is supplied; bounded retained history is a scoped stream policy.
