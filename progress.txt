## Codebase Patterns
- Z-axis incomplete for connections: use `workstationHasZAxisIncompleteForConnections` in `ui/src/features/current-factory-definition/lib/workstation-progress-outcome-routes.ts`; it is true only for standard model processors missing configured `stopWords`, not classifiers or repeaters.
- Progress-outcome connect handle omission uses `workstationSupportsProgressOutcomeRoutes` in the same module; hint visibility must stay aligned with that predicate via the incomplete helper, not a separate flag.
- `ActivityGraphNodeShell` accepts optional `zAxisIncompleteHints: { accessibleLabel, title }` on workstation nodes; renders red pulsing orbs at Continue/Reject right-rail slots aligned to the full four-anchor layout (`workstation-on-continue-source`, `workstation-on-rejection-source`) even when those handles are omitted—query `[data-z-axis-incomplete-hint]` in tests.
- Activity graph wiring: `resolveZAxisIncompleteHints` in `react-flow-current-activity-card-editor-handles.ts` gates hints on `editorMode`, Connect tool (`activeTool === "connect"`), `canInteractWithEditor`, and the incomplete predicate; `buildWorkstationNode` passes the result as `zAxisIncompleteHints` on workstation node data.
- Factory graph wiring: `resolveFactoryGraphZAxisIncompleteHints` in `factory-graph-react-flow-projection.ts` gates on `canEditConnections` and the same incomplete predicate; `FactoryGraphEditorNodeView` passes `data.zAxisIncompleteHints` to `ActivityGraphNodeShell`.
