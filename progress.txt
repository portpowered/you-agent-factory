## Codebase Patterns
- JavaScript workflow source validation belongs in `pkg/workflowvalidation/` using `github.com/tdewolff/parse/v2/js` for syntax/AST checks without executing workflow code.
- File-backed `.js` and supported `.ts` workflow sources load through `workflowvalidation.Load` (stable `SourceHash`, TypeScript syntax stripping, authored-line remapping) before `ValidateLoaded`; integrate from `factoryvalidation.WorkflowSourceTargets`.
- Wire inline workflow validation through `pkg/factory/validation/validate.go` (`javascriptWorkflowConfigAndInlineTargets`); wire file-backed `sourceRef` validation through `validation.Options.WorkflowSourceReader` and `WorkflowSourceTargets`.
- Workflow source lookup and artifact-root validation belong in `pkg/workflowsource/`; normalize API, CLI, MCP, and website requests through `pkg/apisurface/workflow_source.go` (CLI re-export in `pkg/cli/workflowsource/normalize.go`). Lookup order: project `.claude/workflows`, `~/.you-agent-factory/workflows`, package-relative `factory/workflows`, named JavaScript factories, then explicit factory lookup when requested.
- Workflow policy defaults, validation, stable hashing, capability denial, and preview projection belong in `pkg/workflowpolicy/`; normalize API, CLI, MCP, and website policy preview/session-start requests through `pkg/apisurface/workflow_policy.go`. Integrate factory `defaultPolicy` validation through `pkg/factory/validation/validate.go` and session runtime policy hash/budget projection through `pkg/factorysessions/projection.go`.
- Workflow result validation, `you-artifact://sessions/{session_id}/artifacts/{artifact_id}` URI parsing, and `FactorySessionResult.primaryResult` / `SESSION_RESULT_UPDATED` projection belong in `pkg/workflowresult/`; normalize API, CLI, MCP, and website result-shape checks through `pkg/apisurface/workflow_result.go`. Integrate terminal session result reads through `pkg/factorysessions/checkpoints.go` and replay through `pkg/factory/projections/world_state.go`.
- Workflow validation, source resolution, policy preview, and structured-result constraint projection belong in `pkg/workflowpreview/`; normalize through `pkg/apisurface/workflow_preview.go` (`POST /workflow-previews`), CLI `you workflow preview`, MCP `pkg/mcp/workflow/preview.go`, and website `ui/src/api/workflow-preview/` + `ui/src/features/workflow-preview/`.
- `pkg/factory/validation` is at the 15-file pkg-file-count cap; add new validation logic in sibling packages rather than new files in that directory. Do not import `pkg/apisurface` from `pkg/factory/validation` (import cycle via `pkg/config`).
- Artifact-root inside-repo checks should compare `resolvedComparablePath` values so macOS `/var` vs `/private/var` paths and not-yet-created trailing path segments still fail closed.
- Workflow validation issue codes use the `workflow.source.*` prefix and map to `factory.javascript.*` validation target paths.
