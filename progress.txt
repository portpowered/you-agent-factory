## Codebase Patterns
- Recordings capability errors should expose the minimal public classification a peer needs while unwrapping the original cause, so consuming services can preserve family-specific context without importing implementation details.
- Replay diagnostics must use Recordings-owned safe values and cloned version slices; keep raw dependency causes only for `errors.Is`/`errors.As`, and log stable classifications rather than paths, payloads, digests, or error text.
- When a document family is selected before full validation, scan the leading JSON object through its discriminator token so trailing documents still reach the correct family validator and preserve its error context.
- Model Recordings capabilities around their lifecycle scope: pre-ledger path classification and ledger-backed finalized-artifact operations must have non-overlapping contracts, rather than returning unsupported-operation stubs from a shared interface.
- Give canonical event-order validation its own portable diagnostic code and translate it to the Recordings replay diagnostic at the capability boundary; do not collapse it into a generic summary failure.
