## Codebase Patterns
- Graph editor worker add drafts live in `factory-graph-editor-additions.ts`; reuse `parseWorkerArgsText` from `worker-editable-values.ts` for script args parsing.
- `FactoryGraphAddEntityDraft` worker branch uses `workerType` (`MODEL_WORKER` | `SCRIPT_WORKER`) with separate model vs script fields; validation is type-specific in `validateFactoryGraphAddEntityDraft`.
- `addNode` and add-dialog tests must include full worker draft fields (`workerType`, `command`, `argsText`) when constructing worker adds.
- Add-worker dialog gates fields on `draft.workerType`; reuse `getWorkerDetailMessages` for worker type, provider, model, command, and args labels; clearing deselected-type values on type change keeps validation aligned with `validateFactoryGraphAddEntityDraft`.
- Save path tests should chain `addFactoryGraphNode` → `applyFactoryGraphPendingEdits` in `factory-graph-save-input.test.ts`; poller validation uses `workerSupportsPollerBehavior` against the pending factory definition that includes newly added script workers.
