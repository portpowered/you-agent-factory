## Codebase Patterns
- Publish cross-feature dashboard state through Zustand bridges under `ui/src/features/workflow-activity/state/`; expose read helpers (e.g. `readGraphDraftHasPendingChanges`) so consumers avoid graph-editor React hooks.
- Pure current-selection notification resolvers live in `ui/src/features/current-selection/base/lib/` (e.g. `resolveCurrentSelectionGraphDraftConflictNotification`); wire delivery in components/hooks in later stories.
- Graph editor scope changes clear bridge state in `useCurrentActivityGraphEditor` after draft publish effects; scope-reset effect runs second and wins over stale mock draft flags in tests.
- Use `useFactoryGraphTopologyEditorBridge.getState()` for imperative bridge updates inside effects; reset `graphDraftHasPendingChanges` on unmount and session scope change.
- Add current-selection notification copy under `ui/src/features/current-selection/base/messages/` with `LocalizedMessages` catalogs, `get*Messages(locale)` resolver, and locale coverage tests using `SUPPORTED_LOCALES`.
- Deliver graph-draft conflict warnings via `CurrentSelectionGraphDraftConflictNotifications` (render-null Sonner effect) mounted beside each entity `CurrentSelectionSaveNotifications` in `current-selection-widget-save-notifications.tsx`; use `buildSaveErrorStableIdentity` with conflict warning key for dedupe stable identity.
- Classify topology-affecting current-selection saves with `doesFactoryDefinitionChangeAffectGraphTopology` from `factory-graph-topology-impact.ts` (same projection as graph refresh); track `lastSuccessfulSaveWasTopologyAffecting` on `useScopedFactoryDocumentSave` via `previousFactory` + `savedFactoryDefinition` on editable ready state.
- Widget-level graph-draft conflict regressions: set `useFactoryGraphTopologyEditorBridge.getState().setGraphDraftHasPendingChanges(true)` and assert via `expectGraphDraftConflictWarningToast` / `expectNoGraphDraftConflictWarningToast` in `current-selection-save-toast-test-helpers.ts`; use topology-affecting renames or workstation worker assignment for positive cases and model/capacity edits for non-topology negatives.
- Scoped save hook tests that grow past `noExcessiveLinesPerFile` (450 non-blank lines) should split focused `describe` blocks into sibling `*.topology-classification.test.tsx` files (see `useScopedFactoryDocumentSave.scope-isolation.test.tsx`); generic `**/*.test.tsx` override does not raise the file line cap.
