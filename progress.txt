## Codebase Patterns
- Worker editable runtime fields belong on `EditableWorkerValues` / `EditableWorkerDraft` in `worker-editable-values.ts`, with apply logic in `buildWorkerFromDraft` and dirty/equality checks in `use-editable-worker-configuration-state.ts`.
- Model-worker-only controls render inside `ModelWorkerEditableFields`; extract subcomponents when adding fields to stay under Biome `noExcessiveLinesPerFunction`.
- Optional worker booleans like `skipPermissions` use `applyWorkerSkipPermissionsFromDraft` (strip preserved value, set only when draft is true) for all worker types so type changes honor draft state.
- Worker timeout uses `timeoutAmount` + `timeoutUnit` on the draft with `worker-timeout-duration.ts` for Go duration parse/format; apply via `applyWorkerTimeoutFromDraft` in `applyEditableWorkerDraft`, not `pickPreservedWorkerFields`.
- Shared runtime fields (timeout) render between worker type and type-specific fields in `worker-editable-configuration-section.tsx`.
- Overwrite/conflict detection for new worker draft fields requires updates to `editable-worker-overwrite-fields.ts` and `EditableWorkerOverwriteField` in `detail-card-types.ts`.
- Worker `stopToken` uses a draft string field with `applyWorkerStopTokenFromDraft` (trim; empty/whitespace clears); remove `stopToken` from `pickPreservedWorkerFields` so the draft owns the field. Render the shared stop-token input after timeout in `worker-editable-configuration-section.tsx`.
