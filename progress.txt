## Codebase Patterns
- Idle work-state phase colors use `workStatePhaseSurfaceClassName` from `factory-graph-work-state-phase-styling.ts` on dashboard place nodes via `place.state_category`.
- Factory-backed current-activity graph layout must set `state_category` in `placeForFactoryGraphNode` using `stateCategoryByName(factory)`; without it, work-state nodes fall back to neutral surfaces.
- Factory graph editor toolbar copy lives in `ui/src/features/factory-graph-editor/messages/editor.ts`; use concise `toolbar*Label` strings for accessible names and longer `toolbar*Description` strings for tooltips.
- Toolbar icon buttons should use `FactoryGraphEditorTooltipActionButton` (hover + keyboard focus tooltips) rather than plain `DashboardActionButton`.
- Graph node connection-handle buttons use names like `Connect tool: draft Success`; do not confuse those with toolbar `Connect` button renames when updating tests.
- Graph node/edge hover emphasis lives in `ui/src/features/flowchart/lib/current-activity-graph-hover.ts`; use `currentActivityGraphNodeHoverClassName` on node shells and `currentActivityGraphEdgeHoverClassName` / `factoryGraphEditorEdgeHoverClassName` on React Flow edge `className`, with accent stroke CSS on `[data-current-activity-flow] .react-flow__edge.*--hoverable:not(.selected):hover`.
- Topology save-failure inline notices dismiss per `saveAttemptRevision` via `shouldShowGraphSaveFailureNotice`; use `FactoryGraphEditorNotice` `onDismiss` + `noticeDismissLabel` without resetting the save mutation or draft.
- Workstation prompt diagnostics use a single always-mounted `PromptEditorDiagnosticsPanel` in `data-prompt-diagnostics-reserved` (`min-h-24`) inside the autocomplete/help `Collapsible`; hide populated diagnostics with `invisible` when collapsed, auto-expand on 0→N diagnostic transitions, and reset disclosure via `key={state.initialValues.workstationName}` on ready feedback.
- Work-type graph nodes wire `onSelectWorkType` / `selectedWorkType` whenever `shouldWireGraphNodeSelectionHandlers` is true (same as worker/resource/state nodes), not only in factory editor mode; unsupported modes omit the handler so `WorkTypeNodeView` falls back to non-interactive `role="img"` presentation.
- Current-selection expandable sections use `CURRENT_SELECTION_EXPANDABLE_SECTION_BODY_CLASS` for one outer raised shell on expanded content; stack fields with `CURRENT_SELECTION_FORM_FIELD_CLASS` (no per-field outline) inside that shell.
- Use `CurrentSelectionSectionHeader` + `ExpandablePanelTrigger` for history, dispatch attempt, and nested disclosure headers; register new migrated paths in `ui/scripts/dashboard-expand-disclosure-guard-paths.mjs`.
- Current-selection prose cleanup: drop redundant navigation/helper paragraphs (trace guidance, workstation-request pointers, completed-terminal summary, warning detail lines) when headings or alerts already convey the decision; shorten shared-worker/impact catalog strings instead of stacking second `<p>` elements under alerts.
