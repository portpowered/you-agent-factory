## Codebase Patterns
- Feature-owned OpenAPI schema aliases live in `ui/src/features/<feature>/lib/*-types.ts` modules that import from `api/generated/openapi` and export named type aliases.
- Run frontend typecheck via `make typecheck` from the repo root (requires `bun install` in `ui/` first).
- Work-content canonical types: `ui/src/features/work-content/lib/work-content-types.ts` exports `WorkContent` and `WorkContentPart`.
