## Codebase Patterns
- Factory-level execution-family defaults use `modelProvider` with the `ModelProviderSelection` OpenAPI enum (includes symbolic `DEFAULT`); `factory.runner` is rejected at the generated boundary with `factory.runner is retired; use factory.modelProvider`.
- Workstation-level overrides use the same `ModelProviderSelection` enum on `Workstation.yaml`; `workstations[n].runner` is rejected with `workstations[n].runner is retired; use workstations[n].modelProvider`, and AGENTS.md frontmatter rejects `runner` similarly.
- Map factory and workstation `modelProvider` through `internalFactoryModelProviderSelectionFromPublic` / `publicFactoryModelProviderSelectionFromInternal` and `factoryModelProviderSelectionPtrIfNotEmpty` in `pkg/config/factory_config_mapping_internal.go`.
- Runtime provider selection uses `ResolveModelProviderSelection(workstationModelProvider, factoryModelProvider, workerModelProvider)` in `pkg/interfaces/model_provider_selection.go`; it returns concrete CLI `ModelProvider` values plus `ModelProviderSelectionSource` (`workstation`, `factory`, `worker`, `operator_default`).
- `ResolveRunnerSelection` is now a replay/API compatibility adapter over `ResolveModelProviderSelection`; active runtime paths should prefer the provider-native selection and validation helpers.
- Pass factory-level selection through `effectiveFactoryModelProvider` / `WorkstationExecutor.DefaultFactoryModelProvider`; populate `WorkstationExecutionRequest.ModelProvider` before dispatch and keep legacy `RunnerID` only for event compatibility until API story 004/005.
- Built-in prerequisite and capability checks key off canonical provider commands via `workers.BuiltInModelProviderStatus` and `workers.ValidateBuiltInModelProviderPrerequisites`.
- After OpenAPI schema changes, run `go generate -tags=interfaces ./pkg/api ./pkg/generatedclient` even when UI `openapi-typescript` deps are unavailable in the worktree.
- Public dispatch and world-view contracts expose `modelProvider` / `modelProviderSelectionSource` (`WorkerModelProvider` + `ModelProviderSelectionSource`); map internal runner IDs through `GeneratedPublicFactoryWorkerModelProviderFromRunnerOrProviderPtr` and `GeneratedPublicFactoryModelProviderSelectionSourcePtr` at API boundaries.
- Add `x-enum-varnames` to small OpenAPI enums like `FactorySessionTargetRef.kind` so regenerated Go constants keep stable names such as `FactorySessionTargetRefKindDefault`.
- Dispatch request replay metadata maps through `RunnerMetadataFromDispatchRequestMetadata`; legacy replay artifacts normalize `runnerId`/`runnerSelectionSource` to `modelProvider`/`modelProviderSelectionSource` via `replay.normalizeDispatchProviderEvents` during artifact hydration.
- Retired `runner` config fields are rejected before strict OpenAPI decode via `ValidateRetiredFactoryFieldAliasesJSON`; API handlers map boundary errors with `GeneratedFactoryBoundaryValidationMessage` so CLI and API share field-path migration guidance.
- Packaged reference docs under `docs/reference/` embed into `you docs <topic>`; update `tests/functional/smoke/cli_docs_smoke_test.go` and `pkg/cli/docs/docs_test.go` markers when changing customer-facing doc phrases.
- `decodeSaveCurrentFactoryBody` must include every top-level `SaveFactoryForSessionRequest` field on the partial struct used before retired-field validation; otherwise `DisallowUnknownFields()` rejects valid `mode: UPSERT_NAMED_AND_ACTIVATE` payloads.
- World-state dispatch projections should store canonical public `ModelProvider` on `FactoryWorldDispatch` / completions and build `FactoryWorldSelectedModelProviderView` from provider metadata first; legacy `RunnerID` round-trips lose providers like `CLAUDE` that have no runner alias.
- When a PR adds files under `pkg/interfaces` or `pkg/replay`, run `make pkg-file-count` early; consolidate new compat helpers into existing dispatch/artifact files and relocate tests instead of adding standalone `*_compat.go` files.
