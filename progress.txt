## Codebase Patterns
- For an owned Windows subprocess tree that must be cleaned after its direct parent exits, retain a kill-on-close Job Object handle until post-run cleanup; `taskkill` by an already-reaped parent PID cannot prove descendant termination.
- After changing an authored packaged Factory prompt, run `make packaged-factory-catalog-generate`; the prompt, generated Factory artifacts, and manifest are a single checked-in contract.
- Process-boundary client tests must isolate every platform configuration root the child process can consult (HOME, USERPROFILE, APPDATA, LOCALAPPDATA, XDG roots, and package cache) beneath the test temp directory.
- Because `cmd/functionallane` intentionally defaults to `-short`, an opt-in process-boundary test needs its own required non-short CI invocation and a fact-only artifact when its execution is acceptance evidence.
- For a deterministic process-boundary provider effect, put a disposable provider-compatible executable first on the scenario PATH and retain only its provider identity plus invocation count.
- Document `pkg/services/events` as the process-local, in-memory, session-scoped source-native observation stream; Recordings owns canonical Factory Event JSONL history, replay, artifacts, and historical projections.
- Architecture service inventories should name the package that publishes the public owner contract, and diagrams should show direct service operations unless a bounded delivery contract is explicitly involved.
- Define ACP customer terms from the detached `chat_sessions` and `worker_sessions` public contracts; use customer-facing relationship diagrams and keep their event lifetimes separate from Recordings history.
- Event documentation has two shipped contracts only: `workers.Kind`/`workers.Phase` observations retain source provenance, while Recordings `FactoryEvent` JSONL artifacts supply canonical replay history.
- When a PSS decision is superseded, update its canonical record and local planner plan/checklist together, then point all local links to the surviving canonical decision.
- Checklist entries and changed-path inventories that name a current decision document must use its canonical path, not its former planner location.
