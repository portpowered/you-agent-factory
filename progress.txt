## Codebase Patterns
- Website structure guards live in `ui/scripts/check-*.mjs` with companion `*.test.mjs` vitest files and optional `*-allowlist.mjs` debt inventories; wire new guards into both `check` and `lint` scripts in `ui/package.json`.
- Shared UI boundary scans use TypeScript AST import collection on production files under `ui/src/components/ui` only (skip `*.test.*` and `*.stories.tsx`); derive `src/` and repo root paths from the scan root directory so temp-dir tests resolve imports correctly.
- Staged guard debt uses per-violation allowlist entries keyed by `relativeFilePath#importSpecifier`, with stale-entry detection when allowlisted imports disappear without removing the allowlist row.
- Feature shape guards split root topology (`check-feature-root-files.mjs`: no root files, approved root subdirectories only) from cross-feature reuse (`check-feature-boundary.mjs`: production imports under `ui/src/features` must reach other features through a `/public/` path segment).
- Large guard allowlist inventories belong in `scripts/*-allowlist.mjs`; disable Biome `noExcessiveLinesPerFile` for that glob via `biome.jsonc` overrides.
