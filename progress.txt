## Codebase Patterns
- Radix UI primitives (Select, Popover, Dialog) follow the shadcn pattern: re-export Radix Root/Trigger/Value, wrap Content/Item with dashboard semantic tokens via `cn()` and `inputVariants()`.
- Legacy native `<select>` styling lives in `NativeSelect` (`ui/src/components/ui/native-select.tsx`); new dashboard dropdown work should use the Radix `Select` primitives from `ui/src/components/ui/select.tsx`.
- Feature migrations should prefer `EnumSelect`, `OptionalEnumSelect`, and `ResetEnumSelect` from `ui/src/components/ui/enum-select.tsx` instead of hand-rolling Radix wiring for each field.
- Radix Select tests in jsdom need `installDashboardBrowserTestShims()` plus pointer-capture and `scrollIntoView` shims (included in `test-browser-shims.ts`).
- Use `selectLabeledComboboxOption` / `selectComboboxOption` from `ui/src/testing/select-test-helpers.ts` instead of `userEvent.selectOptions` or `fireEvent.change` when asserting migrated dropdown behavior.
- Radix popper sizing CSS variables (`--radix-select-trigger-width`, etc.) require `// tailwind-exception: intrinsic-sizing` comments to pass the spacing-token lint guard.
- `SelectField` composes label, description, and error layout; pass `aria-describedby`, `aria-invalid`, and `id` to `SelectTrigger` for accessible form wiring.
- `SelectContent` prevents default `onCloseAutoFocus` so Radix selects inside dialogs do not fight the dialog focus trap.
- Factory graph add-dialog tests mock `components/ui/dialog` without focus trapping so combobox interactions stay stable in jsdom.
- `EnumSelect` / `OptionalEnumSelect` accept optional `className` on the trigger for surface-specific styling (for example submit-work header density or trend-range emphasis).
- When verifying combobox options in App-shell tests, assert list items before opening the listbox, or close with Escape before querying other regions.
- Feature component dropdowns are guarded by `ui/scripts/check-feature-form-control-usage.mjs`; compose `EnumSelect` / `OptionalEnumSelect` / `ResetEnumSelect` / `SelectField` instead of raw `<select>`, `NativeSelect`, or direct Radix select primitives under `ui/src/features/**/components/`.
