## Codebase Patterns
- Canonical PR verification tiers live in the root `Makefile`: `verify-pr` → `verify-build-contracts` + `verify-tests`; use `run_verification_step` for owned lane labels and exact `make <target>` rerun hints on failure.
- `scripts/ci/run-sharded-ui-coverage.sh` runs `UI_COVERAGE_SHARD=<i>/<total> make ui-test-coverage` shards in parallel (default `UI_COVERAGE_SHARD_TOTAL=10`), then `make test-ui-coverage-merge` for thresholds and replay check; it wipes `ui/.vitest-reports` before shard launch and `sanitizeVitestReportsDirForShardMerge` in `ui-coverage-runner.mjs` strips stale monolithic/out-of-range blobs before `vitest --mergeReports`.
- `scripts/ci/run-concurrent-ui-verification-lanes.sh` orchestrates concurrent `make run-sharded-ui-coverage` and `make ui-integration-test` with `[UI Coverage]` / `[UI Browser Integration]` stdout prefixes and per-lane logs under `.artifacts/concurrent-ui-verification-lanes/`.
- GitHub Actions already runs `ui-coverage-shard` and `ui-browser-integration` as parallel jobs; local `make verify-tests` matches that shard-and-merge plus fast-fail concurrency model.
- Shard main passes use per-shard coverage dirs (`coverage/shard-<index>`) in `ui/scripts/ui-coverage-runner.mjs` so parallel local shards avoid shared `coverage/` races.
- Browser integration harness (`ui/integration/browser-test-harness.mjs`) picks isolated preview/API ports via `findAvailablePort()`, so concurrent browser and covered UI lanes avoid port conflicts when run locally.
- High-cost `App.*` suites can be split by deleting cases already owned by feature/widget tests and moving canonical layout walks onto `CurrentSelectionWidget` harnesses; record before/after timings in `docs/internal/development/ui-*-split-closeout.md`.
- Shared slow-file reporting lives in `ui/scripts/ui-test-cost-report.mjs`; covered UI writes per-shard `ui/.vitest-report-timings/main-shard-<index>-timings.json` (outside `.vitest-reports` so `vitest --mergeReports` only sees Vitest blobs) and merge mode prints `[ui-coverage] Merged main covered pass slowest test files`; browser integration uses `ui/scripts/ui-integration-runner.mjs` with `[ui-browser-integration]` summaries and `[category]` suffixes.
- Verification command smoke tests live in `tests/functional/smoke/verify_fast_command_smoke_test.go` and use wrapper Makefiles to assert tier ordering without running full suites.
- UI test lane boundaries and redundancy policy live in `docs/internal/development/ui-test-lane-boundaries.md`; keep theme/CSS token contracts in jsdom (`styles.page-shell-background.test.ts`, `theme-role-regression.test.ts`) and durable import/export/graph behavior in `ui/integration/*.integration.test.mjs`.
- Browser integration stability (sequential suites, port/download isolation, durable wait helpers) lives in `docs/internal/development/ui-browser-integration-stability.md`; shared checkpoints are `waitForDurableControlEnabled`, `waitForCapturedDownloadOrDialogError`, and `waitForDialogHidden` in `browser-test-harness.mjs`.
